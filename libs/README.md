# Biblioteki współdzielone

Kod używany przez wiele serwisów. Na razie pusto; pierwsza biblioteka powstanie razem z pierwszym serwisem opartym na zdarzeniach.

Planowana zawartość:

- odczyt nagłówków tożsamości ustawianych przez `gateway`,
- publikacja i odbiór zdarzeń CloudEvents zgodnie z kontraktami w [`schemas/`](../schemas/),
- modele wyniku oceny i dowodów.
